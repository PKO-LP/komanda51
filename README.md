## Техническое задание (ТЗ)

1. **Тема сайта:** Образовательный мини-сайт «Курсы по основам HTML и вёрстки».
2. **Структура сайта (2 страницы):**
   - **Страница 1 (`index.html` — Главная):**
     - Заголовок первого уровня (`<h1>`): «Курсы современной веб-разработки».
     - Краткое описание школы в абзаце (`<p>`).
     - Тематическая иллюстрация (`banner.jpg`).
     - Маркированный список (`<ul>`) с преимуществами обучения.
     - Рабочая ссылка (`<a>`) для перехода на вторую страницу (`courses.html`).
   - **Страница 2 (`courses.html` — Программа и запись):**
     - Заголовок первого уровня (`<h1>`): «Программа курса и регистрация».
     - Нумерованный список (`<ol>`) модулей курса.
     - Форма обратной связи: поле ввода имени и активная кнопка «Отправить заявку».
     - Рабочая ссылка (`<a>`) для возврата на главную страницу (`index.html`).
3. **Требования к оформлению и доступности:**
   - Оформление через отдельный файл стилей `style.css` (светлый фон `#f4f6f9`, контрастный тёмный текст `#222222`).
   - Все ссылки и интерактивные элементы должны работать без ошибок.
